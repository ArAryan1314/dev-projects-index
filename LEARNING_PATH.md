# Learning Path: Build-It-Yourself Projects

**121 original projects** across 14 tracks for learning frontend, backend, databases, integrations, AI, DevOps and more (33 beginner, 62 intermediate, 26 advanced).

_Last updated: 2026-11-24. Regenerated by `scripts/build_learning_path.py`._

## How to use this

1. Go track by track. Inside a track, do beginner projects first.
2. Create a **new repo of your own** for each project, using the suggested name, and write the code yourself.
3. The **References** column links permissively licensed projects from this index that solve a similar problem. Read them to learn, and credit them in your README if you reuse any code (keep their license notice).
4. Every repo should have: a README with screenshots and setup steps, tests, a `.env.example`, and a GitHub Actions CI workflow. Deploy it where possible and link the live demo.
5. Tick it off here and link your repo when it's done.

**Recommended languages:** TypeScript (frontend + Node/Bun backend), Python (APIs, automation, AI), SQL (every project), then Go or Java as a second backend language. Bash, Git and Docker throughout.
